一、触发点：AVGO 8/14 暴跌，跌的不是业绩是「表外」

8 月 14 日 AVGO 单日大跌约 -5.94%。拉消息面发现：不是财报问题，不是订单问题，而是三件事叠加，其中最重的一记来自一份信用研报。

  • 美银信用研报：首次系统揭露博通 XPV（XPU 融资平台）的表外风险 —— SPV 购买定制 XPU 租给 Anthropic 等客户，博通提供 残值担保（RVG），满载规模标题值 $3,700 亿（2029 年中峰值），届时优先债务可能累积到该量级。
  • Michael Burry 做空 AI 链：做空 NBIS / ORCL / MU / SOXX，并称英伟达 $5,000 亿融资平台有「安然式操作的影子」。
  • VMware 漏洞事件：ESXi 沙箱逃逸高危漏洞（CVE-2025-6286），影响 vCenter Server 8.0/9.0，给情绪面添了一层压。

图 1-1 XPV 风险的两种口径：$3,700 亿标题 vs $290 亿实际

XPU 融资平台比 GPU 更危险的一点：XPU 没有二级市场。GPU 违约后还能转卖（残值可估），定制 XPU 违约后残值高度不确定 —— RVG 残值担保的「尾部」比英伟达 $5,000 亿平台的更黑。但风险存在恰恰说明这套客户锁定机制在运转。

位置上，AVGO 收在 $393 附近，落在 P09 观察清单档一区间（$380-420）内；$386 斐波那契 0.618 支撑是关键技术位，9/2 Q3 财报是下一个验证点。

二、Google 找 AMD 定制 TPU v10：不是换供应商，是架构代际跳变

同期的另一条消息：Google 与 AMD 达成 TPU v10 合作。初读像是「博通丢了订单」，深读之后结论不同 —— 这是 ASIC 架构的第三代演进，不是简单的供应商替换。

图 2-1 ASIC 三代演进与各家站位

第三代的核心驱动力是物理规律：RL / Agent 是多步推理工作负载，任务规划、工具调用、子代理协同都压在 CPU 上。CPU 与加速器之间 PCIe 总线延迟是微秒级，密集往返时成为瓶颈 —— 解法只有一个：用 3D 混合键合把 CPU die 堆进张量阵列上方（AMD SoIC），延迟降到纳秒级。Intel CEO 陈立武：「CPU:GPU 配比正从 1:8 向 1:1 甚至 4:1 靠拢。」

为什么是 AMD？AMD 是唯一同时拥有三样东西的公司：高性能 CPU IP（EPYC）+ Chiplet 十年经验 + SoIC 3D 堆叠量产能力。英伟达有 Grace 但不做 ASIC；博通会做 ASIC 但没有 CPU IP；Intel 有 CPU 但 ASIC 设计服务刚起步。

三、博通没有看戏：已经打出的五张牌

先厘清一个误解：Google 并没有「离开」博通。2026 年 3 月双方签署五年长期协议，锁定 v8/v9/v10/v11 四代 TPU 设计供应商，合作延续至 2031 年。v9 主订单给联发科、v10 引入 AMD，本质是 Google 的「分享而非替换」双供应商策略。CEO 陈福原：「客户在 COT 领域不会看到竞争，因为我们在这方面远远领先。」

四、CPU 集成化不可逆，博通的结构性裂缝在哪里

三巨头同时押注同一个方向，说明这不是选择而是物理规律：英伟达 Grace+Blackwell（NVLink-C2C）、AMD SoIC、Intel Clearwater Forest 3D 堆叠。但博通没有高性能 CPU IP —— 这是它最真实的弱点。如果未来每颗加速器都必须包含 CPU die，CPU IP 的价值捕获会流向 Arm / AMD / Intel，博通可能从「唯一设计者」降级为「联合设计者 + 封装商」，压缩毛利率。

博通的应对不是补 CPU（那需要十年），而是把 3.5D XDSiP 做成「任何 CPU 都能塞进去」的通用底盘，三个已落地案例：

  • 富士通 Monaka：144 核 ARM CPU（IP 来自 Arm），博通只做封装和 I/O —— 证明它不需要拥有 CPU，只需要知道怎么把 CPU 堆好。
  • OpenAI + Arm + 博通「三国同盟」：Arm 升级为定制 CPU 设计者，博通出 XPU + 3.5D 集成，OpenAI 买单。利润分享 > 股权控制。
  • TPU v9 = MediaTek CPU + 博通 XPU：Google 的「最佳组件」组合模式，博通仍握封装和 XPU 设计。
一句话：AMD 卖的是「整车」，博通卖的是「底盘 + 调校」。大客户要的是后者 —— 因为第一原则是绝不能把计算基础设施的灵魂交给单一供应商。

最需要警惕的情景：不是「AMD 取代博通」，而是客户逐渐把 CPU + ASIC 都交给 AMD 一站式搞定，博通沦为纯网络芯片供应商。早期信号 = AMD 拿下第二个 ASIC 大客户。

五、客户视角：一站式 vs 平台 vs 系统代工，谁更可控

把三条路线放回客户（Google / Meta / OpenAI / Apple）的视角下重排，控制力排序是：博通平台 > Intel 系统代工 > AMD 一站式。

图 5-1 三路线客户控制力光谱

Intel 的「封装先行」为什么聪明：封装验证周期短（EMIB 良率 90%+，比 CoWoS-L 便宜最多 50%）、痛点最明确（CoWoS 被英伟达占 60%+，其他客户排不上队）、地理分散（美国/韩国/马来西亚）。Google 和 Amazon 正在谈每年数十亿美元的封装合同。但 Foundry 仍亏 $21 亿/季、14A 要 2028 年量产 —— 真实竞争者，时间线在 2027-2028 之后。

六、博通收购 ARM 补 CPU？—— 伪命题

直觉上「买 ARM 补短板」很顺，但四堵墙把这条路堵死了：

  1. 英伟达先例已定：2022 年英伟达 $400 亿收购 ARM 被 FTC 起诉阻止。理由：ARM 的核心价值是中立性，被单一芯片公司拥有即失去中立。博通是 ARM 最大的 ASIC 设计客户之一，纵向合并问题完全相同，FTC 直接引用先例即可。
  2. ARM 正被 FTC 反垄断调查（2026 年 5 月启动），节骨眼上被收购等于火上浇油。
  3. SoftBank 不卖：ARM 股价年内近乎翻倍，估值高位，收购溢价会非常惊人。
  4. 收购 = 毁掉 ARM 的价值：高通投奔 RISC-V、苹果加速自研、英伟达全力推 Grace 替代 —— 花千亿美金买一个所有客户都在逃离的空壳。
博通已经在做正确的事：与 Arm 建立合作而非拥有（OpenAI + Arm + 博通三国同盟）。不需要「拥有」Arm，只需要让 Arm 的 CPU 设计离不开博通的封装平台。

七、中国镜像：管制墙内的平行产业链

把中国维度加进来，格局多出一层「地缘镜像」：三条全球路线在中国基本全部缺席（AMD MI 对华禁售、博通在华无 AI 芯片业务、Intel EMIB 曾服务华为后被禁），中国自建了完整镜像链。TrendForce：2026 年中国高端 AI 芯片国产份额约 90%，英伟达/AMD 合计萎缩至 ~10%。

两个关键洞察：其一，CPU 集成化在中国同频发生 —— 鲲鹏 CPU + 昇腾超节点（Atlas 950：1024 卡 1 EFLOPS，可扩 52 万卡）就是中国版「CPU + ASIC 集成」。但中国客户没有 Google 那样的控制力选择权，这是管制强制而非市场选择。其二，封装在中国的权重比全球更高：制程被卡 → 华为「韬定律」用 3D 折叠补制程 → 2026 年约 300 万张国产推理芯片全部需要 2.5D 封装。A 股已在定价：先进封装板块 YTD +54%，昇腾板块 -11%。

八、一页总结与观察指标

核心结论

  1. AVGO 暴跌是表外风险首次被定价，不是基本面恶化：$3,700 亿是满载极端假设，10-Q 实际敞口 $290 亿；美银未下调股票评级。$386 是关键支撑，9/2 Q3 财报验证。
  2. Google-AMD TPU v10 是架构代际跳变，不是供应商替换：第三代 CPU 集成化由 RL/Agent 工作负载和 PCIe 物理瓶颈驱动，不可逆。
  3. 博通护城河的形状在变：从「ASIC 设计垄断」变成「封装平台（3.5D）+ 网络垄断 + 六客户锁定 + XPV 金融锁定」。CPU IP 是真实裂缝，但它选择做「装 CPU 的底盘」而非自研 CPU。
  4. 控制力排序：博通平台 > Intel 系统代工 > AMD 一站式；大客户第一原则 = 绝不把灵魂交给单一供应商。
  5. 博通收购 ARM 是伪命题；中国是地缘镜像市场，先进封装是墙内权重最高环节。

观察指标（后续跟踪）：① AMD 是否拿下第二个 ASIC 大客户；② 9/2 AVGO Q3 财报对 XPV 的披露口径；③ Intel 数十亿美元级封装合同是否落地；④ 长鑫 HBM3 出口能力；⑤ TPU v10 量产参数（CPU die 占比 / SoIC vs 3.5D 用量）。

以上均为个人发散思考与学习笔记，仅作自我复盘用途，不构成任何投资建议。
