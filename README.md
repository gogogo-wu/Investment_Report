## 说明

- 全部为静态 HTML，双击即可打开，无需构建
- **首页支持按「年份 / 月份」筛选查看**：顶部下拉选择年月，目录自动过滤；侧栏导航可一键收起/展开（状态本地记忆）
- **左侧导航按年月收纳分组**：侧栏以「2026 年 7 月 / 2026 年 8 月…」分组，最近月份默认展开、历史月份默认收起，点击组标题展开/收起（状态本地记忆）
- **`index.html` 已改为数据驱动**（2026-08-31 起）：侧栏导航、首页目录、年月筛选器、统计数字全部由 `REPORTS` 表自动生成——新增报告只需在表中加一行
- **2026-08-31 收纳后旧根路径链接（`/Investment_Report/xxx.html`）已失效**，新路径带 `2026/08/` 前缀；历史版本均可通过 git 查看
- **AI 智能体接手仓库：先读 [AGENTS.md](AGENTS.md)（发布管线 / 修正流程 / 风格规范 / 已知坑）**
- 报告中的持仓权重与成本价为个人示例数字，不构成投资建议
- `website/`（learning-dashboard 项目）与 `.workbuddy/`（私人数据）不入库
