九、Intel Foundry 与 ASIC 产业链的联动v3新增

此前在 ASIC 四标的深度建仓分析 中，我们详细讨论了 AVGO 作为"hyperscaler 逃离 NVIDIA+HBM 定价逃生舱"的核心逻辑。Intel 的 Foundry 转型恰恰嵌入了这条 ASIC 产业链——两者不是独立故事，而是同一个产业变迁的两面。

9.1 为什么 hyperscaler 在逃离 NVIDIA？

NVIDIA 卖 GPU 时强制绑定 HBM 类型和数量——hyperscaler 没有 BOM（物料清单）控制权。HBM 涨价 → GPU 成本随之涨（HBM 占 GPU 成本 30-40%）→ hyperscaler 被迫接受 NVIDIA 的定价。而 AVGO 的定制 ASIC 让 hyperscaler 自己定义芯片内存规格 → 可针对推理优化（减少 HBM 用量）→ TCO 省 40-65%。

核心逻辑链：

HBM 涨价 → GPU 成本涨 → ASIC 成本涨幅远小于 GPU（可控内存规格）→ GPU-ASIC 成本差扩大 → 更多 workload 转 ASIC → 2027年 ASIC 出货量反超 GPU（12.5M vs 10.9M）

9.3 闭环逻辑：Intel 增发 ↔ ASIC 趋势

把两个分析放在一起，可以看到一个完整的产业闭环：

环节驱动力受益方
1. HBM 垄断定价 SK Hynix + Micron + Samsung 三巨头控制 HBM 供给，涨价自我毁灭 —（触发因素）
2. Hyperscaler 逃离 NVIDIA GPU-ASIC 成本差扩大，2027年 ASIC 出货量反超 GPU AVGO（ASIC 设计龙头，6大客户锁定）
3. ASIC 需要先进封装 AVGO 设计的 Google TPU / AWS Trainium 需要 EMIB 等异构封装 Intel Foundry（EMIB 已确认客户）
4. ASIC 需要第二晶圆源 TSMC 产能被 NVIDIA 挤占，hyperscaler 需要分散风险 Intel 18A/14A（Tesla 已确认，Apple/Google 在谈）
5. Intel 需要钱扩产 FCF -$440亿，ROIC 2.1%，发债不可能 $200亿增发（5倍超额认购）
6. 资金到位 → 扩产 → 接更多 ASIC 订单 产能扩张满足 AVGO 客户的 ASIC 需求 闭环回到环节 3-4
核心洞察：Intel 增发的 $200亿 不是在"烧钱续命"，而是在为 ASIC 产业链代工产能扩容。$1000亿的机构认购需求之所以如此旺盛，正是因为机构看到了这个闭环——HBM 涨价驱动 ASIC 趋势 → ASIC 需要 Intel 的封装+代工 → Intel 需要钱扩产 → 扩产后能接更多 ASIC 订单。

换句话说：AVGO 是 ASIC 趋势的"设计端"受益者，Intel 是"制造端"受益者。两者是同一枚硬币的两面。

9.5 对投资者的 ASIC × Intel 联动启示

  • AVGO 和 Intel 不是竞争对手，而是供应链上下游。AVGO 设计 ASIC → Intel 封装/代工。AVGO 越强（更多 ASIC 订单），Intel Foundry 的利用率越高
  • EMIB 是 Intel 最被低估的资产。不需要 18A 良率突破就能赚钱——Google TPU 和 AWS Trainium 的封装订单已经在手。这是 Intel 在 ASIC 产业链中"确定性最高"的切入点
  • 18A 是 Intel 的"期权"而非"确定性的赌注"。如果 18A 良率持续提升到 85%+，Apple/Google 代工合同落地 → Intel 从"封装商"升级为"晶圆+封装双供" → 价值量翻倍。如果 18A 失败，Intel 仍有 EMIB + Xeon CPU 两条腿
  • $200亿增发的本质是在为这个闭环"买产能"。机构用 5 倍超额认购表达了对闭环成立概率的判断——即使 ROIC 当前仅 2.1%，但如果 18A + EMIB + ASIC 趋势的闭环跑通，未来 ROIC 有望从 2.1% 跃升至两位数
  • 投资组合含义：如果同时持有 AVGO（设计端）和 Intel（制造端），等于在做多同一个 ASIC 趋势的两端。但需注意相关性风险——AI 泡沫破裂时两端会同时下跌

十、对投资者的核心启示

  1. ROIC 是一切融资决策的锚。当 ROIC > 债务成本时，发债 = 为股东套利；当 ROIC < 债务成本时，发债 = 自杀，发股 = 唯一出路。
  2. "确定性回报"在实际中极少存在。企业嘴上说确定性，ROIC 方差可能极大。Intel 代工业务的 ROIC 不确定性，正是其被市场惩罚的核心原因。
  3. 增发的信号效应不可忽视。管理层选择发股而非发债，等于间接承认"我们不确定能赚回比利息更多的钱"——这对股价本身就是利空。
  4. 但机构会用真金白银覆盖利空信号。$1000亿认购需求证明：即使 ROIC 极低、FCF 为负，只要转型叙事足够强（代工+AI+地缘政治），机构依然愿意买入。
  5. FCF 连续五年为负是极大的红旗。$440 亿累计 FCF 亏损意味着公司商业模式本身无法自给自足——不是在投资成长，是在烧钱续命。
  6. 价格反应 = 稀释比例，不等于恐慌。4% 稀释 → 跌 4%，这是市场的机械定价。真正的态度要看认购——而认购的答案是"5倍超额"。
  7. ASIC 产业链的"设计端"和"制造端"是同一枚硬币的两面。AVGO 设计 Google TPU/AWS Trainium → Intel EMIB 封装 → Intel 18A 可能代工下一代。做多 ASIC 趋势不应只看设计端（AVGO），还要看制造端（Intel Foundry）。
  8. EMIB 是 Intel 最被低估的确定性资产。不需要 18A 突破就能贡献收入——Google TPU 和 AWS Trainium 的封装订单已经在手。

结论

Intel 增发从 $150亿 扩至 $200亿，获得 $1000亿 认购需求（5倍超额），定价 $95 折让仅 2.6%——市场用真金白银买账了。这不是对 Intel 当前基本面的认可（ROIC 2.1%、FCF -$440亿），而是对"代工转型 + AI 需求 + 地缘政治"叙事的押注。

与甲骨文的对比依然成立：ROIC 决定融资路径——甲骨文 9.7% → 发债套利，Intel 2.1% → 发股续命。但 Intel 的案例多了一层启示：即使 ROIC 极低，只要叙事足够强，市场依然愿意提供资金。关键在于这笔钱能否真正跑通"EMIB 封装 + 18A 代工 + ASIC 产能"的闭环。

从 ASIC 产业链视角看，Intel Foundry 和 AVGO 不是竞争对手，而是供应链上下游——AVGO 设计的 ASIC 需要 Intel 的封装和代工。$200亿 增发的本质，是在为这个闭环"买产能"。
